🔐 Налаштування GitHub Secret

⚠️ Важливо: Цей токен вже використовується для автентифікації. Додайте його як секрет у вашому репозиторії.

Крок 1: Відкрийте сторінку секретів

Натисніть кнопку нижче, щоб відкрити сторінку налаштувань секретів:

Відкрити GitHub Secrets

Крок 2: Створіть новий секрет

  1. Натисніть кнопку "New repository secret"
  2. У полі "Name" введіть: GHCR_TOKEN
  3. У полі "Value" вставте токен знизу:
[Вставте ваш Personal Access Token тут]

Крок 3: Збережіть секрет

Натисніть кнопку "Add secret" для збереження.

Крок 4: Перевірте workflow

Після додавання секрету:

  1. Перейдіть до GitHub Actions
  2. Зробіть новий push до гілки develop
  3. Перевірте, що workflow виконується успішно
📝 Примітка: Після додавання секрету workflow автоматично запуститься при наступному push до гілки develop.
